# Редактор квитанции Альфа-Банк СБП (PDF)

Специализированное веб-приложение для квитанций Альфа-Банк (СБП C2B) с автоматическим рендерингом оригинального PDF и заменой целевых полей:

1. **Назначение платежа**:
   - Дата поездки (по умолчанию сегодня / возможность ручного ввода)
   - Время поездки (текущее время или ручной ввод)
   - Номер автобуса / маршрута (например, `14`)
   - Текст формируется автоматически в точности как в оригинале:
     `Оплата поездки от [Дата] [Время], Автобус`
     `[Номер]`
   - Доступен режим ручного редактирования текста при необходимости.

2. **Дата отправки перевода**:
   - Формат с секундами и часовым поясом (например: `03.09.2026 11:53:21 мск`).
   - Кнопка **«⏱️ Поставить текущее время»** в 1 клик.
   - Опция синхронизации даты вверху справа («Сформирована» +4 минуты).

3. **Сумма платежа**:
   - По умолчанию всегда стоит **40 RUR**.
   - Можно менять на любую сумму, есть кнопка быстрого возврата к 40.

4. **Форматы сохранения**:
   - **📄 Скачать PDF** — сохраняет настоящий векторный PDF документ формата А4 в оригинальном разрешении.
   - **🖼️ Скачать PNG** — сохраняет изображение высокого разрешения.
   - **📋 Скопировать фото** — помещает картинку в буфер обмена для мгновенной отправки (`Ctrl + V`).
